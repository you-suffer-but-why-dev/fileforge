# fileforge

Forge any file. In your browser.

Client-side file converter — no upload, no server, no accounts. All conversion
runs locally in the browser with [pdf.js](https://mozilla.github.io/pdf.js/) and
[pdf-lib](https://pdf-lib.js.org/).

## Tools

| Tool | Status |
|------|--------|
| PDF ↔ Markdown | scaffold |
| Split / Join PDF | scaffold |
| PDF → PNG | scaffold |
| Image → PDF | scaffold |
| Table → CSV | scaffold |
| EPUB → TXT | scaffold |

UI built from a DESIGN.md (see `DESIGN.md`) following minimalist × bento,
dark-mode-native, glassmorphism references.

## Privacy

Files never leave your device. Nothing is uploaded to any server.

## Develop

Static site — just open `index.html`, or serve locally:

```bash
npx serve .
```

## Deploy

Connected to Vercel. Push to `main` to deploy.
